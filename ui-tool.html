Space to build your ideas

Draw & arrange

Create shapes, frames, sections, straight pen paths and freehand drawings. Group layers, move and resize them, align edges and distribute spacing.

Find your type

Search 1,959 Google Fonts families, preview your own text and download families when needed. Twenty-four popular families work offline. The Mac app also lists installed fonts.

Shape a layout

Use basic rows, stacks or fixed-column grids with gap and uniform padding. Adjust dimensions, fills, strokes, typography, simple shadow and blur.

Keep it editable

Organize pages and nested layers. Save portable .oui projects, undo changes, make local named snapshots, and return to recent files on this device.

Preview a flow

Connect a layer to a destination frame and present simple click-through navigation. Add local canvas notes and inspect basic CSS for a selected layer.

Move between tools

Export SVG, PNG or JPEG at 1×–4×. The included Figma Bridge development plugin transfers a supported subset of editable layers through .oui, with reduction reports.

In the v0.1.0 download, Figma Bridge is a preview integration, with automated API-mock checks. A real Figma desktop plugin round trip still needs validation. Direct binary .fig import/export, full components/variants, rich text, advanced prototyping, Motion and live collaboration are not included.

Before you begin

A few useful answers

Is this a complete Figma clone?

No. Oanarina is an independent app with a large parity roadmap. The notarized download is v0.1.0; the separate 0.2.0-dev.3 source adds the local workspaces described above. Both have documented limits, and substantial parity work remains.

Can I import and export Figma projects?

Use the included Figma Bridge development plugin for a supported subset of editable .oui layers, or SVG for visual exchange. Read its transfer report and compatibility guide. Binary .fig import/export is not implemented.

Are all fonts included?

The catalog has 1,959 Google Fonts families as of October 29, 2026, with 24 popular families bundled. Other families download when selected. Commercial fonts can be used when installed and licensed; they are not redistributed. The v0.1.0 installer does not include the new italic/import workflows. Current development source adds genuine italic faces, licensed TTF/OTF import and missing-family replacement; see the development section.

Does it work offline?

Core editing, bundled fonts and project files work locally. Additional Google Fonts need a network connection the first time. Browser recovery has storage limits; save a .oui file for a portable backup. The standalone MCP server is also local and requires Node.js 22+; it does not synchronize a currently open editor.

Is there a Windows version?

Mac is the first platform. Windows is planned after the Mac workflow is further developed and validated.

Where can I find help?

Read the user guide, inspect the source repository, or send feedback through the contact page.
