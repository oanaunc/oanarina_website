Start a study

Choose one of eight studios, add a drawing, image or PDF page, and describe what the result should explain. Set treatment, palette, light, context, view, format and quality. You can edit the full prompt before generating.

All eight core tools, 30 lessons, local folios, source comparisons and the basic board layouts are free. Image generation with your own OpenAI key requires an OpenAI API account with available billing; a ChatGPT subscription does not include API usage.

Included credits and Studio Plus

Optional monthly subscriptions include managed AI credits and advanced presentation features. Standard studies use 1 credit; High studies use 3. A coordinated three-study set uses three requests. Monthly credits reset without rollover. Credit packs do not expire and do not unlock Plus features. Prices and exact included amounts appear before purchase in the app.

Plus adds coordinated three-study sets, four extra page layouts, studio branding, A1 PDF export, multi-project portfolio PDFs and distraction-free presentation. Apple manages renewals and cancellation.

Restore or recover

Use Restore Purchases to recover an active subscription or unfinished purchase. Finished consumable packs are not restored by Apple. Keep the private recovery ID from You if you need to recover an existing credit balance on another device. Treat it like a password and share it only privately with support when needed.

A study failed

Failed managed generations return reserved credits. If the connection drops after a generation completes, check your balance and Folios before starting another. Please send only the request reference, approximate time and a description of the issue. Never email your OpenAI key.

Export and protect your work

Folios are stored on the device. Use Share or Board Studio to export images and PDFs. Native board composition preserves image proportions and adds real typeset titles and captions without sending data to AI.

Report or delete

Use Report this AI result for unsuitable output. You → Your data & AI consent controls future AI requests and data deletion. See the privacy policy. Subscription terms use Apple’s Standard EULA.
