Privacy & your files

October 29, 2026 · version 0.1.0

Local editing

The preview does not require an account, upload your design to a server, or include app analytics. Projects you explicitly save stay at the destination you choose. Recovery copies, recent files, comments and snapshots are stored on this device, subject to browser storage limits.

Local resource server

The native Mac app serves its bundled public editor files only on 127.0.0.1:51981. User project files are not served by that HTTP server. The native bridge handles only the app’s main-frame requests.

Google Fonts

Twenty-four font families are bundled. If you preview or apply another family, the app contacts fonts.googleapis.com and fonts.gstatic.com. Those services receive the normal network request, including your IP address and the requested font. The app does not send your design text as a font-subsetting request. Downloaded font data is cached locally.

Installed fonts

The native picker reads installed font family names through macOS. It does not copy proprietary font files into projects. Use fonts under their own licenses.

Figma Bridge

The development plugin exchanges .oui files you choose and requires no network access itself. Figma’s own service and policies apply when you run it there. Import/export may create new pages in the Figma file you have open.

Development source

The separate 0.2.0-dev.5 source adds local SVG review and editable import, layer masks, selection navigation, layer organization, preferences and action search. Preferences and the most recent 20 distinct action IDs are stored locally outside .oui projects. Action history contains command IDs, not project names, content or file paths. Reset preferences and Clear recent actions operate separately from project data. SVG input is parsed as data; source scripts, event handlers and external references are not executed or fetched. Unsupported content can be omitted or reduced, as shown in the review dialog. Mask and selection edits remain in the local document. These additions are not part of the v0.1.0 installer. See the development guide.

Your control

Export .oui for a portable backup. Remove local browser/site data to clear recovery, local histories and downloaded-font caches; save important projects first. Files you explicitly exported are managed separately through Finder.
