    Preview guide and compatibility
    Upgrading from Oanarina UI Tool? Quit the older app, open the DMG and copy Forma.app to Applications. The new filename does not replace Oanarina UI Tool.app automatically. After confirming Forma opens your work, you may remove only the old application bundle. Keep your .oui projects, backups and app data. The same bundle ID preserves compatible local data; there is no silent updater.

    Design foundations · current preview

    Space to build your ideas

    Draw & arrange

    Create shapes, frames, sections, straight pen paths and freehand drawings. Group layers, move and resize them, align edges and distribute spacing.

    Find your type

    Search 1,959 Google Fonts families, preview your own text and download families when needed. Twenty-four popular families work offline. The Mac app also lists installed fonts.

    Shape a layout

    Use basic rows, stacks or fixed-column grids with gap and uniform padding. Adjust dimensions, fills, strokes, typography, simple shadow and blur.

    Keep it editable

    Duplicate, reorder and search pages, organize nested layers and save portable .oui projects. Undo edits, make local named snapshots and return to recent files on this device.

    Preview a flow

    Connect a layer to a destination frame and present simple click-through navigation. Add local canvas notes and inspect basic CSS for a selected layer.

    Move between tools

    Export SVG, PNG or JPEG at 1×–4×. The included Figma Bridge development plugin transfers a supported subset of editable layers through .oui, with reduction reports.

    Figma Bridge remains a subset integration. Automated and synthetic connected-API transfers have run; the installed desktop plugin UI and full-fidelity round trip still need validation. Local binary .fig Design import now supports a documented subset. Binary .fig export and cloud multiplayer are not implemented.

    New in the dev.14 preview

    Tested in the real app. Fixed where it counts.

    This preview comes from running Forma inside its real Mac shell, which found problems browser tests could not show. Forma works offline, and your files stay on your Mac. Many areas remain partial, with limits documented in the guide.

    Fixed for your Mac

    File pickers now open for images, PDF, fonts, plugins and audio. PowerPoint, Markdown, palette and code exports save, and full screen works. Update if you use dev.13 or earlier. What was fixed.

    Video with sound

    Export MP4 and WebM frame by frame using H.264, VP9, AAC and Opus, with a soundtrack from a frame or a WAV. Shaders animate in preview and export. Video export.

    Talk through a prototype

    Press C in a running prototype to pause and pin a comment to the frame. Threads save in your file, with replies and Undo. Exported player files do not carry comments. Prototype comments.

    Annotate on the canvas

    Add notes and live measurements directly on the canvas, including gaps, centers and painted bounds. Manage categories across the file. Annotations never enter exported artwork. Annotations.

    Resize that stays real

    Drag a group handle and its layers take real sizes, with strokes, radii and type unchanged. Frames and sections can keep fitted to their contents. Groups and fit.

    Color you can convert

    Convert a file between sRGB and Display P3 with appearance preserved, after a review that counts clipped colors. Files with linked libraries refuse. Color conversion.

    Hand off to native code

    Generate SwiftUI, UIKit, Compose and XML for one layer, with density, Dynamic Type and Material type details. SwiftUI and UIKit output was type-checked once; Android output is uncompiled. Native output.

    Closer to your Mac

    Drop files from Finder, paste text, images and SVG from other apps, sample screen colors and use installed font faces. Shortcuts follow QWERTZ, AZERTY, Dvorak and Colemak. Mac integration.

    This is a development preview. Multiplayer, accounts, hosted publishing and AI generation are not included. Substantial design parity, full-fidelity interchange and binary .fig export remain unfinished. Preview change notes.

    Pages that stay organized

    Duplicate, reorder, rename, delete or search pages. Remember each Design/Whiteboard page’s view locally and preview artwork on hover or focus. Unsafe referenced deletion is refused. Page tools.

    Fit your workspace

    Collapse or resize sidebars with pointer and keyboard controls, add a portable project description, open file actions from the title and browse bundled release notes. Workspace controls.

    Move artwork between pages

    Move supported complete layer trees with stable identities and live local component links in one Undo step. Unsafe split connections or inherited context are refused before editing. Move scope and safeguards.

    Responsive grid tracks

    Your local file library

    Browse thumbnails or lists, search and sort, organize flat local folders, star or pin files, and use Archive or recoverable Trash. Import validated .oui batches atomically; permanently removing a file requires confirmation. Local files and recovery.

    Mac document windows

    Open separate Design, Whiteboard and Slides windows, route commands to the active document, reopen recent files and handle unsaved changes per window. Local sessions can restore available recovery copies. Window behavior and safeguards.

    Whiteboard

    Editable sticky notes, labeled connectors, tables, mind maps, marker/highlighter ink, stamps, a local timer and local voting. Undo and .oui persistence share the design editor. Tools and limits.

    Slides

    Character formatting

    Apply family, size, weight, italic, color, decoration and links to selected character ranges. Supported font axes and OpenType settings render locally; rich clipboard and .oui preserve formatting. Typography guide.

    Interactive prototypes

    Author multiple actions, variables and conditions, overlays, scrolling, variant changes and transitions. Play flows locally with a separate preview state. Prototype guide.

    Fonts that travel

    Search 1,959 Google families; 24 work offline, with true italic files in 17 families. Import licensed TTF/OTF files, resolve missing families and embed available used faces within the 50 MB project limit. Fonts and licensing.

    Editable SVG import

    Review a supported SVG as editable shapes, paths, groups and text before adding it. See reductions, cancel safely, or choose a sanitized single visual asset. Unsupported masks, filters and other SVG behavior are reported. Import support and limits.

    Layer masks

    Use shapes, text, images or groups as alpha, vector or luminance masks. Layer-tree indicators identify sources, modes and nearest affected artwork. Keep layers editable, release with Undo, and export actual coverage. Mask guide.

    Layers and organization

    Navigate nested artwork, deep-select with Command, and use tree ranges and toggles. Drag layers to reorder or reparent with transform preflight, filter by type, expand descendants, and preview batch names before one undoable edit. Layer-tree guide.

    Your local preferences

    Follow system light/dark appearance and reduced motion, or choose local overrides. Set nudge steps, rotation snapping, wheel zoom, right-button pan, retained tools and new-artwork defaults. Settings stay on this device, outside project files, with validation and reset. Preferences guide.

    Transform and align

    Use a rotation handle, lock each layer’s aspect ratio, or Option-resize around its center. Align a child to its parent or a multi-selection in world space; Shift uses parent alignment. Unsupported skew is rejected before mutation. Transform behavior.

    Actions from the keyboard

    Search registered commands and drawing tools by name, category or related words. Use arrows and Enter to run a result, see shortcuts, and revisit 20 recent distinct actions. History stores command IDs locally and can be cleared. Action search.

    Editable Mac clipboard

    Copy supported editable layers between Mac windows. Paste PNG/TIFF pixels from another app, or use Copy as PNG for a transparent 2× selection snapshot. Raster limits apply; browser system-image clipboard remains unfinished. Clipboard scope and limits.

    A canvas of your own

    Set a page’s canvas color, opacity and visibility, then reset it to follow the theme. Undo and .oui preserve changes; frames, prototypes and artwork exports retain their own backgrounds. Canvas backgrounds.

    Check color contrast

    Compare an explicit foreground/background pair, composite foreground opacity and review normal/large-text AA and AAA thresholds. Copy a supported selected solid paint; this is a helper rather than an automatic accessibility audit. Contrast checker.

    Before you begin

    A few useful answers

    Is this a complete Figma clone?

    No. Forma is an independent app with a large parity roadmap. The current editor is the 0.2.0-dev.14 preview. It has documented limits, and substantial parity work remains.

    Can I import and export Figma projects?

    Use the Figma Bridge development plugin for a supported subset of editable .oui layers and linked components, or SVG for visual exchange. Read its transfer report and compatibility guide. Open supported local binary .fig Design files with File → Open project, review the import report and save a .oui copy. Components become detached editable layers; supported native annotation blocks use their own visual snapshots. Full appearance parity and binary .fig export are not implemented. Read the import limits.

    Are all fonts included?

    The catalog has 1,959 Google Fonts families as of October 29, 2026, with 24 popular families bundled. Other families download when selected. Commercial fonts can be used when installed and licensed; they are not redistributed. The current preview includes genuine italic faces, licensed TTF/OTF import and missing-family replacement; font licensing and embedding limits still apply.

    Does it work offline?

    Core editing, bundled fonts and project files work locally. Additional Google Fonts need a network connection the first time. Browser recovery has storage limits; save a .oui file for a portable backup. The standalone MCP server is also local and requires Node.js 22+; it does not synchronize a currently open editor.

    Is there a Windows version?

    Mac is the first platform. Windows is planned after the Mac workflow is further developed and validated.

    Where can I find help?

    Read the user guide, browse the feature register, or send feedback through the contact page.
