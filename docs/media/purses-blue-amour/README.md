# Blue Amour purse header

Created in the user’s open Midjourney browser on 21 November 2026, using a wide crop of the supplied Blue Amour product photograph as the start frame. One HD video was requested. The original download and crop remain in the local Downloads/purse workflow, outside deployment.

The 5.21-second web film is silent H.264 at 1280×720, with faststart and half-second keyframes for forward and backward scroll seeking. Its poster is the first encoded frame. `purses` uses the same shared scroll engine as Jackets, including motion controls, reduced-motion and data-saving fallbacks, and release of offscreen video buffers.

The page copies the Jackets layout. Eight supplied photographs have 300×250 WebP thumbnails and full-composition gallery copies fitted within 960×1280, matching the latest jacket project. `images.json` records their source filenames and order.
