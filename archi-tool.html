    From the first line to the finished building

    A studio for architecture

    Draft with precision

    Lines, polylines, arcs, splines and hatches with object snaps, polar and object tracking, dynamic input, layers, blocks and dimensions. Trim, extend, offset, fillet, array and stretch, all from the command line or the ribbon.

    Build with real elements

    Levels, layered walls that join cleanly, doors and windows that cut their openings, floors, roofs with overhangs, stairs, railings, curtain walls, columns and rooms that find their own boundaries and areas.

    Model in 3D

    Extrude, revolve, sweep and loft; solids with union, subtract and intersect; parametric families, terrain from contours, section boxes and six visual styles from wireframe to sketchy.

    Render the light

    A sun for your site and hour, lighting presets, textured materials with bump and roughness, soft shadows, bloom and ambient occlusion. Save stills, walkthrough videos and 360° panoramas.

    Draw the sheets

    Sheets with title blocks, viewports at scale, elevations and sections, schedules of doors, windows and rooms, then plot to PDF or publish a whole set in one multi-page file.

    Check the design

    Areas and volumes, clash detection, code checks for stairs and egress, sun and shadow studies, energy estimates and quantity take-offs that update as you draw.

    Work with others

    Open and save DXF for AutoCAD, exchange IFC with Revit and ArchiCAD, read Rhino, send glTF, USDZ, OBJ and STEP, share BCF issues and keep versions you can compare and restore.

    Script it

    A JavaScript console, visual node graphs, macros and plugins. Every command, typed or clicked, can be recorded and replayed.

    Design with an AI

    A built-in Model Context Protocol server lets Claude and other agents read the model and draw walls, rooms and sheets with you, on your own computer only, and only when you turn it on.

      // A row of houses, each one a real building element
for (let i = 0; i < 4; i++) {
  const x = i * 14000
  const w = [[x,0],[x+10000,0],[x+10000,8000],[x,8000]]
  w.forEach((p, k) => archi.wall(...p, ...w[(k+1)%4], { height: 3200 }))
  archi.slab(w, { thickness: 250 })
  archi.addElement({ type: "roof", boundary: w, kind: "gable", pitch: 35 })
}
archi.run("ZOOM E")

      A few useful details

      Before you begin

      Is it really free?

      Yes. Oanarina Archi Tool is free software under the GNU General Public License 3.0: no account, no subscription and no watermark.

      Can I open my AutoCAD, Revit or SketchUp work?

      Open and save DXF, the exchange format AutoCAD, LibreCAD and most CAD tools read and write; save DWG files as DXF first. Exchange building models as IFC with Revit, ArchiCAD and other BIM tools. Rhino 3DM files open directly; SketchUp files open through a free converter.

      Does it work offline?

      Yes. Drawings and models stay on your computer. The optional agent server listens only on your own computer and is off until you turn it on.

      How complete is it?

      1114 of the 1157 capabilities in the public feature register are built and tested. The remaining ones are marked openly in the register, most of them waiting for outside validation.

      Who makes Oanarina Archi Tool?

      Oanarina Archi Tool is developed by Oana Rinaldi, with ideas drawn from the open-source FreeCAD, LibreCAD, IfcOpenShell, SolveSpace, OpenSCAD, BRL-CAD, Sverchok and CAD Sketcher communities.

      How can I share feedback?

      Report a reproducible problem or suggest an improvement through the contact page. Include your macOS or Windows version and the steps that led to the problem.
